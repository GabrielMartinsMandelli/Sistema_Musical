# 🎵 Sistema Musical

Sistema simples para gerenciamento e organização de músicas, artistas e listas de reprodução.

## 🚀 Funcionalidades

- Cadastro e consulta de músicas e artistas
- Criação e gerenciamento de playlists
- Organização simples de acervo musical
